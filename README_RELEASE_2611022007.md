# 羅家英文冒險島 V2.2 雲端同步版

將解壓後所有內容上傳至同一GitHub Pages網站根目錄，保留cloud及stories資料夾，不要多包一層目錄。上傳前先匯出原網站JSON備份並備份網站檔案；使用相同網站網址才能保留原瀏覽器本機資料。

家長登入同一家庭帳號，在角色對應介面將姊姊、弟弟各自連結既有雲端孩子。不同裝置登入相同帳號並選同一孩子，讀取相同雲端進度。未登入仍保留原本機模式。離線作答等待伺服器確認後才正式入點。

舊本機點數、獎勵申請與學習紀錄不會自動匯入；承接功能保持關閉，雲端餘額可能與本機不同，請勿清除瀏覽器資料。正式承接前先備份、預覽、對帳及另行確認。

iPhone/iPad用Safari分享→加入主畫面；Android Chrome選單→安裝/加入主畫面；電腦Chrome/Edge可安裝或直接開啟。網站需HTTPS，首次連網載入後才可離線。此包為PWA，沒有APK或IPA。更新後關閉舊視窗並重新開啟；若未更新，先重新整理，勿清除本機儲存。

資料庫結構、RLS及匿名RPC權限已唯讀確認；自動化測試與本機合成Chrome驗收不等於正式帳號跨裝置、跨家庭JWT或手機實機驗收。這些仍須實測。未自動推送、部署或匯入資料。
